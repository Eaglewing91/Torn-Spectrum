# Changelog

## 1.5.0
- New **Pause animated images**: freezes animated profile pictures, signatures and honor bars on profile pages (or everywhere on Torn). Tap a paused image to play it. Uses only images already loaded, so it makes no requests

## 1.4.0
- New **Dark** overlay: dims the whole screen at your chosen strength (works in light and dark mode)

## 1.3.1
- Fix: the script now waits for the page to exist before starting, so it can't fail when a manager (e.g. Torn PDA) injects it very early
- Added forum post and screenshots in `docs/`

## 1.3.0 — First public release
- Colour layers: Calm, Low stimulation, Paper, Night warm, Greyscale, High contrast
- Colour-blind assist: Protan, Deutan and Tritan
- Coloured reading overlays with strength control and automatic light/dark matching
- Brightness, contrast and colour fine-tune sliders
- Reading ruler, reduce motion, readable font, extra text spacing, underline links, strong focus outline
- "Torn Spectrum" entry in the avatar menu, under Dark Mode
- Torn PDA support (Android & iOS)
